# BioLaunch Landing Page

Static landing page for BioLaunch.

## Run locally

From this folder:

```powershell
python -m http.server 8123 --bind 127.0.0.1
```

Open:

```text
http://127.0.0.1:8123
```

## Deployment

This is a static site designed for Vercel. The VSL is embedded from Vidzflow and the booking calendar is embedded from GoHighLevel, so no large local video files need to be committed.
